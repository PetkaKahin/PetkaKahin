# Локальный просмотр

Открой `preview.html` двойным щелчком в файловом менеджере. Нужен только браузер: сервер, установка пакетов, Git и публикация не требуются.

Вверху можно переключить ширину на телефон и выбрать светлую или тёмную тему. Это приближение к оформлению README на GitHub. Внутри README фон, текст, декор и все промежутки между панелями нарисованы в SVG. Сам GitHub управляет внешней страницей и полями вокруг README.

Графика и анимации хранятся в `assets/` и работают офлайн. Профиль собран в одном HTML-абзаце из плотно состыкованных SVG-полос. Боковые поля и вертикальные интервалы включены в каждое изображение; выравнивание `<img align="top">` устраняет зазор под строкой. Между изображениями нет пробелов, `<br>` и отдельных абзацев. Поэтому фон GitHub не виден между панелями; уменьшение ширины и светлая тема не нарушают композицию.

Карточки проектов ведут сразу в репозитории или на сайт. Описание, технологии и компактная схема проекта видны без раскрытия. Стандартные `<details>` убраны ради непрерывного фона. Навигация по разделам использует обычные `<a>`. JavaScript для профиля не нужен. Анимации учитывают настройку уменьшения движения в системе.

Публичные репозитории посчитаны через GitHub; дата снимка указана на панели статистики. Остальные счётчики показывают количество представленных проектов, технологий и направлений. Это не живая статистика коммитов или процентов владения навыками. Значения не обновляются автоматически.

3D-карта и график за 30 дней строятся из `activity.json`: снимка публично отображаемого календаря GitHub. Показатель contributions включает виды активности, которые учитывает GitHub, и не равен только числу коммитов. Даты, дневные значения и уровни активности берутся из календаря; названия репозиториев и сообщения коммитов не сохраняются.

Чтобы обновить графики, скачай календарь и импортируй его, затем пересобери профиль:

```bash
curl -fL https://github.com/users/PetkaKahin/contributions -o /tmp/profile-contributions.html
python3 scripts/update-activity.py /tmp/profile-contributions.html
python3 scripts/build-assets.py
python3 scripts/preview.py
```

Либо `python3 scripts/update-activity.py` скачает календарь сам. Обновление графиков требует интернета; готовый предпросмотр работает офлайн.

Содержимое профиля задаётся в `profile.json`. В нём нет почты, Telegram и биографии. После изменения данных пересобери графику и README, затем предпросмотр:

```bash
python3 scripts/build-assets.py
python3 scripts/preview.py
```

Затем обнови страницу браузера. `scripts/preview.py` использует только стандартную библиотеку Python и копирует содержимое README в локальную оболочку, не отправляя его в сеть. Если менялся только README, достаточно запустить этот скрипт. Пересборка SVG заново создаёт README из `profile.json`.

Для пересборки графики нужны Python Cairo и установленные шрифты Rajdhani и Play. Готовые SVG уже содержат контуры букв: для просмотра эти зависимости не нужны.

Ограничения GitHub: пользовательские стили и JavaScript из README удаляются. Верхнее меню, боковая колонка, общий фон github.com и встроенная лента активности не меняются. SVG задают вид внутри блока README, а интерактивность ограничена ссылками и раскрывающимися секциями. SVG в `<img>` поддерживает анимацию по времени, но не получает hover или событие раскрытия родительского `<details>`. Собственная плавная анимация высоты/закрытия также требует CSS или JavaScript страницы. Предпросмотр не подменяет эти ограничения дополнительными эффектами.

Пример ARCANGEL0 использует те же средства: SVG с печатающимся текстом, GIF, картинки статистики и отдельную 3D-карту, а не замену фона GitHub. Проверен исходник: https://github.com/ARCANGEL0/ARCANGEL0/blob/master/README.md. Ограничения рендеринга: https://github.com/github/markup; поведение SVG-изображений: https://www.w3.org/TR/SVG2/conform.html#secure-animated-mode.
